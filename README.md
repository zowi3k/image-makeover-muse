# Image Makeover Muse

Создай современный мобильный интерфейс для Telegram Mini App — ИИ-фотостудии "PixelMagic". Сделай стильный тёмный дизайн (dark mode) с неоновыми фиолетово-синими акцентами. На главном экране должны быть:

1. Область для загрузки фотографии с телефона с красивым предпросмотром.

2. Горизонтальная лента с карточками стилей на выбор: "Студийное фото", "Киберпанк", "Аниме", "Киношный свет", "Удалить фон".

3. Поле для своего текстового описания (необязательно).

4. Большая яркая кнопка "Сгенерировать" внизу экрана.

5. Экран результата с анимацией загрузки, сравнением "До / После" и кнопками "Скачать" и "Попробовать другой стиль".
